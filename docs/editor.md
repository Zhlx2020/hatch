# 跳声明与书签

## 跳声明

光标下方的名字要能找到它的声明，按 `F12`、`Ctrl+B` 或者 `Ctrl+点击`（macOS 上是 `Cmd`）。

- C 文件里认函数定义、函数声明、`#define` 宏、`typedef` 类型和全局变量。
- 汇编里认 `名字:` 标签和 `名字 equ/db/dw/dd/dq` 数据。
- 只有一处落点就直接过去；多处先把候选列在编辑区下沿，点一条过去，`Enter` 取第一条，`Esc` 关掉。

排序规矩：定义在声明前面，然后是同一目录、同一工程、整个工作区。搜索是纯文本的，不用先编译，语法还没写完也能跳。

名字取的是光标所在的那个词；光标落在缩进里时取本行第一个词。找到的位置会和断点一样把文件打开、标签切到树里选中。

接口：`POST /api/declare {path, word}` → `{word, kind, hits: [{file, line, kind, def, text}]}`。没有落点返回空数组，词不合法返回 400。

## 书签

F11 给当前行加一条书签，同一行再按一次取消。书签存在 `workspace/bookmarks.json`，跟着人走而不是跟着某个工程走，所以换工程也还在，最多 200 条。

左下角的书签栏列出 `文件名:行号` 和那一行的内容：

- 点 `文件名:行号` 打开那个文件并跳过去（双击整行也一样）
- 行尾的 `×` 删这一条，栏头的「清空」全删
- 文件被删掉的那条打上删除线并留着，点它不跳，方便回头找

接口：`GET /api/bookmarks`、`POST /api/bookmarks {file, line, text}`（切换）、`DELETE /api/bookmarks {file, line}`。
