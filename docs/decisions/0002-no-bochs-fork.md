# 0002 不 fork Bochs，直到必要

## 结论
只调用 Bochs 二进制，不改一行源码。界面完全自绘。

## 理由
- 它的 GUI 调试器（Enhanced Debugger）是 83KB 手写 Win32 控件、直连 `bx_dbg_*`，
  颜色写死、无布局器；改外观等于改绘制代码。
- 调试器核心与界面无关：命令、寄存器、内存、页表全在核心，文本协议已实测够用。
- 不 fork 就没有编译链负担，也没有上游漂移的跟进成本。

## 何时才 fork
仅当需要「事件推送、结构化状态」这类文本协议表达不了的东西时，在 `init_debug_dialog()`
那层抽接口再补一个前端，`win32`/`wx` 原样保留。届时要处理调试器单线程模型。
