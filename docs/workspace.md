# 工作区约定

`workspace/` 就是项目目录，左边栏直接映射它。

| 项 | 说明 |
| --- | --- |
| 目录 | 任意层级，名字 `[A-Za-z0-9_.-]`，用于分模块 |
| `.asm` | 可汇编的入口文件，末尾必须有 `times 510-($-$$) db 0` 与 `dw 0xaa55` |
| `.inc` | `%include` 片段，不能单独运行，编辑器不做保存校验 |
| `.c` `.h` | C 源文件与头文件，必须位于带 `oslab.toml` 的工程目录里才能运行 |
| `oslab.toml` | 工程清单：`kind`、`entry`、`sources`、`boot`、`link`、`base`，文件里就地写着每条规则的用例 |
| `settings.toml` | 工作区根上的启动开关与 QEMU 参数，界面可改 |
| `.md` `.txt` | 只读文本，可放在目录里当笔记 |

## 规则

- 路径始终是相对 `workspace/` 的 `/` 分隔串，段内不许空格，不许 `..`。
- 汇编时会把源文件所在目录作为 `nasm -i` 的搜索路径，所以同级 `%include "x.inc"` 可用。
- 运行哪个文件由左栏选中项决定；崩溃或语法错误不会连带杀掉上一台机器。
- 运行入口先看清单：有 `oslab.toml` 就按它走，没有才把 `.asm` 当单文件工程。
- 清单只说文件构成；按钮文字、入口暂停这些挂在运行按钮的「启动方式」里，清单再写 `[run]` 会报错。
- 清单写错就当场报错并点名：不认识的键、`asm` 工程里写 `sources`/`boot`/`link`、`entry` 不在 `sources` 里、`base` 越界或没对齐，都不会被静默忽略。
- 新增语言只需在 `services/build.py` 注册后缀并写一个处理函数，上层不动。
