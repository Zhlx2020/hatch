# 工作区约定

`workspace/` 就是项目目录，左边栏直接映射它。

| 项 | 说明 |
| --- | --- |
| 目录 | 任意层级，名字 `[A-Za-z0-9_.-]`，用于分模块 |
| `.asm` | 可汇编的入口文件，末尾必须有 `times 510-($-$$) db 0` 与 `dw 0xaa55` |
| `.inc` | `%include` 片段，不能单独运行，编辑器不做保存校验 |
| `.c` `.h` | 预留，尚未接入工具链 |
| `.md` `.txt` | 只读文本，可放在目录里当笔记 |

## 规则

- 路径始终是相对 `workspace/` 的 `/` 分隔串，段内不许空格，不许 `..`。
- 汇编时会把源文件所在目录作为 `nasm -i` 的搜索路径，所以同级 `%include "x.inc"` 可用。
- 运行哪个文件由左栏选中项决定；崩溃或语法错误不会连带杀掉上一台机器。
- 只有 `.asm` 会走 `services/build.py` 的分派；新增语言只需注册新后缀，不动上层。
